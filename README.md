# 瞬時に話せる英会話大特訓 Webリーダー (全90 UNIT 完全版)

『瞬時に話せる英会話大特訓』の全90 UNIT（全800問）を収録した、PC・タブレット・スマートフォン対応のインタラクティブWebリーダーです。

🌐 **オンライン版URL (GitHub Pages)**:  
👉 **[https://mmchan2525.github.io/shunji-eikaiwa/](https://mmchan2525.github.io/shunji-eikaiwa/)**

---

## 📱 主な特徴

### 1. スマートフォン完全対応（モバイル専用フラッシュカードUI）
- **Q&Aペア表示**: スマホの縦画面に最適化され、日本語問題の直下に英語解答が配置された単語帳スタイルでサクサク学習可能。
- **左右スワイプ操作**: 指で画面を左右にスワイプするだけで、前後のUNITへ直感的にページめくり。
- **暗記テストモード**: 英語解答をすりガラス状に隠し、タップで1問ずつパッと答え合わせ。
- **片手操作ナビゲーション**: 画面下部にスティッキー配置された操作バー（iPhoneのセーフエリア完全対応）。

### 2. PC・タブレット向け：全画面フィット（見開き・スクロールゼロ）
- **📐 全画面フィット（Fit to Screen）**: ブラウザのウィンドウサイズに合わせて自動伸縮。左右見開き（左: 日本語問題、右: 英語解答・解説・ヒント・発音）が縦スクロール一切なしで1画面にピタリと収まります。
- **📜 スクロールモード切替**: 好みに応じて通常スクロール表示へワンクリックで切り替え可能。

### 3. 高精度テキスト ＆ 充実の学習補助機能
- **原書完全照合**: 全90 UNIT（800項目）を原本スキャンと1文字単位で照合・校正。OCR誤読や単語結合を徹底排除。
- **音声読み上げ（TTS）**: ブラウザ標準の Web Speech API を活用し、各英文の「🔊」個別再生およびUNIT内の自動連続再生に対応。
- **全文インクリメンタル検索**: 日本語・英語の双方から全90 UNIT・800問を瞬時に検索し、対象UNITへジャンプ可能。
- **3つのカラーテーマ**: 紙面ライクな「標準（ペーパー）」、清潔感のある「ホワイト」、夜間学習に最適な「ダーク」を切り替え可能。

## 📲 スマホのホーム画面に追加してアプリ化する方法

本Webリーダーは PWA (Progressive Web App) 対応タグが組み込まれており、ホーム画面に追加することでブラウザのアドレスバーなしの**ネイティブアプリ感覚**で利用できます。

### iPhone (Safari) の場合
1. Safariで [https://mmchan2525.github.io/shunji-eikaiwa/](https://mmchan2525.github.io/shunji-eikaiwa/) を開きます。
2. 画面下部中央の **共有ボタン**（四角から上矢印が出ているアイコン）をタップします。
3. メニューから **「ホーム画面に追加」** を選択します。
4. 右上の **「追加」** をタップすると、ホーム画面に専用アイコンが配置されます。

### Android (Chrome) の場合
1. Chromeで [https://mmchan2525.github.io/shunji-eikaiwa/](https://mmchan2525.github.io/shunji-eikaiwa/) を開きます。
2. 右上のメニュー（縦の3点リーダー）をタップします。
3. **「ホーム画面に追加」** または **「アプリをインストール」** を選択します。

## ⚙️ GitHub Pages 公開設定

もし上記URLでページが表示されない場合は、本リポジトリの設定で GitHub Pages を有効にしてください。

1. 本リポジトリの **[Settings]** タブを開きます。
2. 左メニューの **[Pages]** をクリックします。
3. **[Build and deployment]** > **[Source]** で以下のいずれかを選択します：
   - **`GitHub Actions`** を選択（本リポジトリに含まれるワークフローにより自動ビルド・デプロイされます）  
     *または*
   - **`Deploy from a branch`** を選択し、Branchに **`main`**、フォルダに **`/(root)`** を指定して **[Save]** をクリック。
4. 数分待つと `https://mmchan2525.github.io/shunji-eikaiwa/` にて公開されます。
